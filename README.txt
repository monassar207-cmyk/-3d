# كتاب الدراسات الاجتماعية التفاعلي ثلاثي الأبعاد

## التشغيل
1. فك ضغط الحزمة.
2. افتح مجلد المشروع في VS Code.
3. شغّل `index.html` عبر إضافة Live Server أو أي خادم محلي ثابت.
4. افتح الرابط في متصفح حديث يدعم WebGL.

يمكن فتح `index.html` مباشرة لمعاينة الواجهة، لكن عارض صفحات المصدر وخدمة PWA يعملان بصورة أفضل عبر خادم محلي أو HTTPS.

## المحتويات
- `index.html`: التطبيق التفاعلي.
- `lesson_schema.json`: مخطط الوحدات والدروس والأسئلة والحقائق والأهداف.
- `pages/`: صور صفحات الكتاب الأصلي الـ112 بجودة مضغوطة، لعرضها داخل الدروس.
- `cover.png`: صورة الغلاف.
- `manifest.webmanifest` و`sw.js`: إعدادات التثبيت والتخزين المؤقت.
- `icons/`: أيقونات التطبيق.

## ملاحظات تقنية
- الرسوم ثلاثية الأبعاد تعتمد على Three.js وOrbitControls من CDN، لذلك يلزم اتصال بالإنترنت لتحميل مكتبات العرض أول مرة، ولا نعتبر محرك 3D يعمل دون اتصال في هذه النسخة.
- يقوم Service Worker بتخزين ملفات التطبيق وصفحات الكتاب محليًا بعد أول زيارة عبر HTTPS أو localhost.
- حفظ تقدم الدروس محلي على الجهاز عبر localStorage.
- بيانات الأهداف والحقائق في `lesson_schema.json` مأخوذة من فهرس الكتاب وصفحات افتتاحية تمت مراجعتها بصريًا. الأسئلة والتفسيرات والمجسمات صياغة تعليمية مساعدة، وليست نصًا حرفيًا من الكتاب. يجب استكمال تدقيق بقية صفحات كل درس قبل استخدام المحتوى كمرجع امتحاني نهائي.
